* Purpose

This directory contains reusable templates for accessibility-related
activities. These templates standardise accessibility reporting, VPAT
documentation and accessibility statements.

* Templates

| Template                                                     | Description                               |
+--------------------------------------------------------------+-------------------------------------------+
| [[file:./accessibility-report.org][Accessibility Report]]       | Standard format for audit findings.       |
| [[file:./accessibility-statement.org][Accessibility Statement]]    | Public-facing accessibility statement.    |

* Usage

Each template should be copied into the relevant project directory and
customised. Reports should reference specific WCAG criteria.
