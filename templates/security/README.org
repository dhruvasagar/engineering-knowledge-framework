* Purpose

This directory contains reusable templates for security engineering
activities. These templates standardise threat modelling, security
review reporting and security testing documentation.

* Templates

| Template                      | Description                                     |
|-------------------------------+-------------------------------------------------|
| [[file:./threat-model.org][Threat Model Template]] | Structured threat model document using STRIDE.  |
| [[file:./security-review-report.org][Security Review Report]] | Findings report for security review outcomes.   |

* Usage

Each template should be copied into the relevant project directory and
customised. Templates follow the conventions established in the
[[file:../../handbooks/security/README.org][Security Engineering Handbook]] and the
[[file:../../playbooks/security-review/README.org][Security Review Playbook]].
