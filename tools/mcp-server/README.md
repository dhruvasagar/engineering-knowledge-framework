# Engineering Knowledge Framework MCP Server

An [MCP](https://modelcontextprotocol.io/) server that exposes the
Engineering Knowledge Framework's knowledge graph, documents, and
context pack generation as resources and tools for AI assistants.

## Quick Start

```bash
# Make sure the knowledge graph is built first
cd ../..
make graph

# Start the MCP server over stdio
./run.sh
```

Or from the repo root:

```bash
make mcp-server
```

## Prerequisites

- Python 3.10+
- `uv` (for the virtual environment) — or the venv is created automatically
  by `run.sh`

The first run creates a virtual environment and installs the `mcp` package
automatically.

## Resources

The server exposes the following resources that AI assistants can read:

| Resource                         | Description                                                                                     |
|----------------------------------|-------------------------------------------------------------------------------------------------|
| `knowledge://capabilities`       | List all capabilities with document counts and completeness status                              |
| `knowledge://capability/{name}`  | All documents in a capability (e.g., `Rails%20Engineering`)                                     |
| `knowledge://doc/{encoded-path}` | Content of a specific document. Use `__` for `/` in paths (e.g., `handbooks__rails__README.md`) |
| `knowledge://graph/stats`        | Knowledge graph statistics and most-connected documents                                         |
| `knowledge://search?q={query}`   | Search documents by title, description, and path                                                |

## Tools

The server exposes the following tools that AI assistants can call:

| Tool                     | Description                                                                                                                        |
|--------------------------|------------------------------------------------------------------------------------------------------------------------------------|
| `generate-context-pack`  | Generate a condensed AI context pack from a capability name, document path, or search term. Configurable depth and document count. |
| `find-related-documents` | Find documents related to a given path via knowledge graph cross-references                                                        |
| `search-knowledge`       | Search across all framework documents                                                                                              |
| `capability-report`      | Get per-capability completeness report showing which document types are present and missing                                        |
| `read-document`          | Read a specific document by path                                                                                                   |

## Prompts

The server exposes prompt templates that AI assistants can use:

| Prompt                | Description                                                |
|-----------------------|------------------------------------------------------------|
| `engineering-review`  | Template for code, design, or documentation review context |
| `architecture-review` | Template for architectural decision review                 |
| `rails-development`   | Template for Rails development tasks                       |

## Configuring MCP Clients

### Claude Desktop

Add to your `claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "engineering-knowledge-framework": {
      "command": "/path/to/engineering-knowledge-framework/tools/mcp-server/run.sh",
      "args": []
    }
  }
}
```

### Claude Code

```bash
claude mcp add engineering-knowledge-framework \
  --command /path/to/engineering-knowledge-framework/tools/mcp-server/run.sh
```

### Other MCP Clients

Any MCP-compatible client can connect using stdio transport:

```bash
/path/to/engineering-knowledge-framework/tools/mcp-server/run.sh
```

## Architecture

The server uses the [FastMCP](https://github.com/modelcontextprotocol/python-sdk)
Python SDK and runs over stdio transport.

It loads the knowledge graph from `tools/output/knowledge-graph.json`
(generated by `make graph`) and reads documents directly from the
repository.

```
                    ┌───────────────────────┐
                    │     MCP Client        │
                    │    (Claude, etc.)     │
                    └──────────┬────────────┘
                               │ stdio JSON-RPC
                    ┌──────────▼────────────┐
                    │      MCP Server       │
                    │     (server.py)       │
                    ├───────────────────────┤
                    │ Resources │ Tools     │
                    │           │ Prompts   │
                    └──────────┬────────────┘
                               │
                    ┌──────────▼────────────┐
                    │    Knowledge Graph    │
                    │ (knowledge-graph.json)│
                    └───────────────────────┘
```

## Development

The server is a single Python file at `server.py`. The virtual
environment is created by `run.sh` on first use.

To manually set up the environment:

```bash
cd tools/mcp-server
uv venv .venv
uv pip install mcp
```

To test the server:

```bash
cd ../..
python3 -c "
import anyio
from mcp.client.session import ClientSession
from mcp.client.stdio import stdio_client
from mcp import StdioServerParameters

async def test():
    params = StdioServerParameters(
        command='./tools/mcp-server/.venv/bin/python',
        args=['tools/mcp-server/server.py'],
    )
    async with stdio_client(params) as (read, write):
        async with ClientSession(read, write) as session:
            await session.initialize()
            tools = await session.list_tools()
            print(f'Tools: {len(tools.tools)}')
            for t in tools.tools:
                print(f'  - {t.name}')

anyio.run(test)
"
```
