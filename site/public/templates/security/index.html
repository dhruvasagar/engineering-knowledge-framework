Reusable templates for security engineering workflows

Purpose

This directory contains reusable templates for security engineering activities. These templates standardise threat modelling, security review reporting and security testing documentation.

Usage

Each template should be copied into the relevant project directory and customised. Templates follow the conventions established in the Security Engineering Handbook and the Security Review Playbook.
