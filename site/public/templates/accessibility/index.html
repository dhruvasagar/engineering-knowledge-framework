Accessibility Templates

Reusable templates for accessibility engineering

Purpose

This directory contains reusable templates for accessibility-related activities. These templates standardise accessibility reporting, VPAT documentation and accessibility statements.

Templates

| Template | Description | +--------------------------------------------------------------+-------------------------------------------+

Accessibility ReportStandard format for audit findings.

Usage

Each template should be copied into the relevant project directory and customised. Reports should reference specific WCAG criteria.
