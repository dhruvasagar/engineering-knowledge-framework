Engineering Quality Learning Paths

Structured learning progression for engineering quality

Purpose

These learning paths provide a structured progression through engineering quality practices, from following quality standards to establishing quality processes across teams.

Beginner Path

Objective

Follow quality standards, participate in code reviews and write tests consistently.

Prerequisites

  • Basic understanding of software development workflows.

Topics

  1. Quality Principles

    • Quality is a shared responsibility.
    • Prevent defects, don't just find them.
    • Reference: Engineering Quality Handbook

  2. Code Review Participation

    • What to look for in a review.
    • Writing constructive review comments.
    • Reference: Code Review Standards Guide

  3. Testing Basics

    • Test pyramid and test distribution.
    • Writing meaningful tests.
    • Reference: Testing Strategies Guide

  4. Following Quality Gates

    • Understanding pre-commit, PR, deploy and release gates.
    • Reference: Engineering Quality Handbook

Assessment

Demonstrate by: Consistently writing tests, participating in code reviews and passing quality gates without blockers.

Intermediate Path

Objective

Define quality metrics, lead code reviews and manage technical debt.

Prerequisites

  • Completed Beginner Path or equivalent experience.

Topics

  1. Quality Metrics

    • Measuring code and process quality.
    • Tracking trends and setting targets.
    • Reference: Quality Metrics Guide

  2. Leading Code Reviews

    • Reviewing for design and architecture.
    • Mentoring junior reviewers.
    • Reference: Code Review Playbook

  3. Technical Debt Management

    • Identifying and classifying debt.
    • Prioritising and tracking remediation.
    • Reference: Technical Debt Management Guide

  4. Quality Dashboards

    • Building and maintaining quality dashboards.
    • Using metrics for continuous improvement.

Assessment

Demonstrate by: Leading code reviews that catch design issues. Tracking and reducing technical debt in a codebase.

Advanced Path

Objective

Establish quality standards across teams, design quality programmes and mentor quality practices.

Prerequisites

  • Completed Intermediate Path or equivalent experience.

Topics

  1. Quality Programme Design

    • Defining quality standards for an organization.
    • Balancing quality investment with delivery velocity.

  2. Quality Culture

    • Building a blame-free quality culture.
    • Incentivising quality without gaming metrics.
    • Reference: Engineering Quality Handbook

  3. Cross-Capability Quality

    • Quality standards across multiple teams.
    • Integrating quality into the development lifecycle.

  4. Mentoring Quality Practices

    • Training teams on quality practices.
    • Reviewing quality metrics across teams.

Assessment

Demonstrate by: Establishing quality standards for an organization. Mentoring teams on quality practices. Driving measurable quality improvements.
