Code Review Severity Labels

| Label | Meaning | +-------------+-------------------------------------------------------+

BLOCKERMust be fixed before merge. Design flaw, correctness
issue, security vulnerability.
+-------------+-------------------------------------------------------+
SHOULD FIXImportant but not blocking. Follow-up required.
+-------------+-------------------------------------------------------+
NICE TO HAVESuggestion for improvement. Can be deferred.
+-------------+-------------------------------------------------------+
QUESTIONClarification needed. Not a change request.
+-------------+-------------------------------------------------------+
